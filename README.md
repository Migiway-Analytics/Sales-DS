## 📌 Описание проекта
Данный проект представляет собой полноценный **End-to-End Data Science пайплайн** для анализа розничных продаж и оценки маржинальности бизнеса. Основной фокус исследования направлен на трансформацию транзакционных логов в бизнес-метрики, сегментацию продаж по устройствам и географии, а также подготовку оптимизированной аналитической витрины для BI-систем.

Проект демонстрирует применение практик Data Engineering (очистка, обогащение, генерация признаков) для создания надежного фундамента под интерактивную управленческую отчетность.

## ⚙️ Этапы реализации пайплайна в Python

### 1. Разведочный анализ данных (EDA) и Очистка
* Первичный аудит структуры данных, типов переменных и распределения базовых величин.
* Проверка на целостность данных: обработка пропущенных значений, фильтрация некорректных транзакций и системных аномалий.

### 2. Глубокий Feature Engineering (Проектирование признаков)
Для того чтобы раскрыть потенциал данных для бизнеса, в ходе пайплайна были созданы новые аналитические разрезы:
* **Временные маркеры:** выделение года, месяца, а также флага выходного дня (`IsWeekend`), что позволяет находить паттерны покупательской активности в зависимости от календарных факторов.
* **Юнит-экономика и Финансы:** на основе базовых цен и объемов были рассчитаны ключевые метрики прибыльности для каждой строки заказа:
  * Общая выручка (`Revenue`)
  * Себестоимость (`Cost`)
  * Валовая прибыль (`Profit`)
  * Рентабельность продаж (`Profit_Margin`)
* **Обогащение данных:** интеграция профилей клиентов (`customer_name`) для будущей персонализации аналитики.

### 3. Формирование финальной витрины для Power BI
Все обработанные и сгенерированные признаки фильтруются и собираются в финальный датасет со строгой структурой (`columns_for_bi`). Код экспортирует готовый к промышленному использованию файл `retail_sales_for_bi.csv`, что исключает необходимость тяжелой предобработки на стороне BI-системы.

## 📊 Интерактивный дашборд Power BI
Экспортированная витрина данных служит единственным источником правды (Single Source of Truth) для разработанного бизнес-отчета:

1. **Executive Summary (Панель руководителя):** Общие KPI бизнеса — совокупная выручка, общая прибыль, средняя маржинальность сети и динамика выполнения планов.
2. **Sales Performance & Tech Segment:** Анализ продаж в разрезе типов устройств (`Device`) и каналов трафика, выявление наиболее маржинальных платформ.
3. **Geographical & Customer Analysis:** Распределение продаж по странам и макро-регионам (`CountryGroup`), а также рейтинг ключевых клиентов по объёму приносимой прибыли.
